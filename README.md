# The Last Login — Chapter One

A text-first psychological horror / cold-case investigation game.

You are reviewing a recovered forensic image tied to the 2019 disappearance of Lena Ortiz. The case was closed as a voluntary disappearance. The archive raises questions the original investigation did not answer.

## Play locally

Open `index.html` in a browser.

For development, VS Code + Live Server works well.

## Deploy

This repository is configured as a Render static site with `render.yaml`.

## Features

- recovered files, mail, messages, and search
- evidence board and clue connections
- progressive 3-level hints
- forensic terminal
- scanned evidence images
- original looping background music
- subtle notification and system sounds
- Chapter One recap

All characters, agencies, locations, and events are fictional.
